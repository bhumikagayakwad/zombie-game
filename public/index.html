C++ OBJECT-ORIENTED DESIGN GUIDE

Designed for college evaluations and viva presentations. Every concept is directly linked to source code.

Inheritance

Base Class Entity

Player, Zombie, Bullet, and Supply derive from abstract Entity, inheriting spatial coordinates (m_x, m_y), bounding radius, and active status.

class Player : public Entity { ... };
class Zombie : public Entity { ... };
Encapsulation

Health & Weapon Safety

Internal state variables are strictly private. Health invariants (0 ≤ current ≤ max) and non-negative ammo boundaries are enforced via methods, never direct mutation.

void Health::heal(float amount) {
    m_current = std::min(m_current + amount, m_max);
}
Composition

"Has-A" Relationships

Player has-a Health object and has-a Weapon object. Game has-a Player and std::vector containers of entities, promoting modularity over deep inheritance trees.

class Player : public Entity {
    Health m_health;
    Weapon m_weapon;
};
Polymorphism

Virtual update(dt)

The base class Entity declares virtual void update(float dt) = 0. Each derived entity overrides this with customized physics (ballistic for Bullets, AI chase for Zombies).

void Zombie::update(float dt) override;
void Bullet::update(float dt) override;

5 Top College Viva Questions & Answers

Q1: Why use WebAssembly (WASM) instead of writing all the game logic in JavaScript?
WASM allows high-performance, deterministic C++ simulation code to run near-native speed in browser sandboxes. It decouples the core domain model (physics, collision, state) from the rendering platform.
Q2: How does the Player class demonstrate Composition over Inheritance?
Player inherits from Entity ("is-an Entity"), but composes Health and Weapon ("has-a Health", "has-a Weapon"). This allows swapping weapons or health logic without touching the player class hierarchy.
Q3: Why is the destructor of Entity marked as virtual?
Virtual destructors prevent memory leaks when deleting derived objects (like Zombie or Player) through base-class pointers (Entity*).
Q4: How are collisions calculated without external physics libraries?
Circle-circle Euclidean collision: (dx² + dy²) ≤ (r₁ + r₂)². This avoids expensive square roots unless needed, keeping updates ultra-fast across hundreds of entities.
Q5: How does delta-time (dt) ensure consistent gameplay?
Multiplying velocities by dt ensures player and zombie movement distance depends on actual elapsed real time rather than the monitor's frame rate (60Hz, 120Hz, etc.).
